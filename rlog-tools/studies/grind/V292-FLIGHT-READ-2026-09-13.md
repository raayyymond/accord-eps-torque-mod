- **`v292_flight_creep.py`'s final presence section** (ALL-engaged, r6c's 6 215 windows) was still running
  at hand-off; its band tables in §3 are transcribed from the live log, and its ALL-engaged presence
  numbers are superseded by §3.1, which computes the same predicate.
- **Two scripts had an ordering defect on first run** (`v292_flight_phase.py` missing a positional
  argument; `v292_flight_decay.py` dividing by r6c's baseline before r6c was reached in the loop). Both
  are fixed in place; the b5/b6 ratios in §6 were computed from the reweighted values the run printed.
- **The pre-registered hands-off CREEP 1–3 m/s stratum is thin** — 16.0 / 50.9 / 16.2 s across the three
  routes, fragmented, so only r6e supports a pooled spectrum and none supports the 2 s presence window.
  The V292 drives were not creep drives. Every creep number carries that caveat.
- **The high-angle hands-OFF stratum is not scorable on any V292 route** (< 3 s of runs ≥ 1 s). At
  |angle| ≥ 30 the operator holds the wheel, so the hands-on/hands-off split at high angle is answered
  only for hands-LIGHT (|bar| < 1216) vs hands-ON (≥ 1216).
- **No fork checkout on this machine**, so the code defaults behind the wiped `Accord*` params were not
  read. That is an open item and it matters: `AccordRatePlantFF` defaulting the other way is a real change
  to the outer loop.
- **I did not re-derive the plant family, `B(f)`, or the replay's predictions.** They are inherited and named.
- **The chain mirror is the record's**, with its known single-floor defect, and is used only for `sp`,
  `ref_deg` and the rail duties.
- **The F7 counts are small** (7 vs 1). The continuous statistics, not the counts, carry the weight.
