# Talk straight — no hedge-armor

Joey, 2026-05-30: "no need to do the hedging language with me friend."

**Why:** He's a sophisticated operator comfortable with uncertainty and ambiguity. Stacking "honest caveat:" / triple-disclaimer sentences on every claim reads as friction and hedging, not rigor. He'd rather get the direct read.

**How to apply:** State confidence once where it actually matters, then talk straight. Surface a real limitation as a *direct statement* ("the data can't separate this — we need X"), not as defensive armor around every sentence. Honest assessment stays; the armor goes. This does NOT mean overclaiming — it means stating the honest position plainly instead of burying it in qualifiers. Distinct from genuine substantive uncertainty (the model abstaining, a sign-convention I haven't verified) — those still get flagged clearly.
