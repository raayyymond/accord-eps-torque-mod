2020 Accord EPS firmware: the angle-loop release, read from the image

What this is: the LKAS code path of the Renesas V850E2 image 39990-TVA-A160, stock and as modified by the release V300 rev 2 (fw id 39990-TVA,A16C). openpilot sends a steering-angle setpoint on CAN 0xE4; a 1 kHz loop in the EPS closes on the measured angle through a 260-byte code cave and Honda's own PID, with Honda's hand fade as the only override. Every number on this page was read from the stock dump and the release image; E = evidence with its method, B = belief.

4. Risk, before the drive

Lane authority stays 6× Honda's E

Rail 2461 T = 15360 × 0.990 × 254/256 × 5346 ≫ 15. Stock: × 891 under a 512 clamp = 410 T. Unchanged since V282; the loop's P/I/D were sized on it.

EME protection ≈ 5× looser, all driving EB

Honda's excessive-effort ladder 1024 → 5120 (corridor ±5.0 / floor 5.0, int + float) is a kept ×6 cell. Permissive only; V38…V267 flew with it on Honda's banks.

Two Honda interlocks stay off E

The V36/V37 package disables the driver-torque-transient STEER_STATUS trip and the DTC-0x49 over-torque counter (stock 0xC64B4..B8 = 112/96/54/64/112 → 255), as on every flown build since V37.

Hands-on feel returns to Honda's EB

Damper banks, Coulomb relay knee/K1 and the biquad are stock again after ≈ 6 weeks on modified banks. One lane is kept: DampAxis (curve). Magnitude of the feel change is a belief.

GATE 2 re-score: DampAxis kept E

Reverting the DampAxis lane drops GM at 3 m/s from 20 to 5.2 dB (peak +5.4 dB, Ms 1.26 → 2.68), so rev 2 keeps its 13 bytes. The r24 gate/arm revert passes (ΔPM −0.7…+0.1°, GM ≥ 20 dB).

Stock camera: lane inert, not stock LKAS E

With a stock camera the field is never 2, so E′ = 0: V300 is Honda base assist only. A stock camera cannot steer through this firmware.

No ramp-out on request drop E

A2 skips the PID on the first request-0 tick: lane torque goes to 0 at once through the 5 Hz lag, instead of Honda's 0.5 s ramp-out (arm 2).

Loop live below 5 km/h E

The low-speed lockout 0xC62EA is 0 (stock 320 ≈ 5 km/h). Kept by decision: the goal says every speed.

Hand fade, direction-2 arm E

The fork's field = 2 selects arm 2; its record 0xE54FC carries arm 0's curve (0.86 at 1200 counts, floor 0.30 above 2048). The cave's 1229 freeze is Honda's hands-on level.

Nothing on the wire but F181 EB

0x14A byte 4 bits 3–7 and byte 7 bits 6–7 are no longer forced; the 0x1AB torque tap is gone. Only the fw id identifies the build.

7. The stock path, stage by stage

7.1 0xE4 reception, FUN_00052676

raw      = s16((b0 << 8) | b1)                 # STEER_TORQUE, big-endian; under the mod this IS the angle setpoint: θ_sp = −raw (0.1°)
gp_69ae  = clamp(−4·raw, −0x4000, 0x4000)      # st.h @0x526F2
gp_6803  = (b2 << 28) >> 30   # byte 2 bits 3:2  (logical shr @0x526F6) — the camera-interlock field
gp_6805  = b2 >> 7            # byte 2 bit 7 = STEER_TORQUE_REQUEST
gp_6804  = (b2 << 25) >> 31 ; gp_6802 = b2 & 3 ; gp_67f3 = b3 >> 7 (debounced)
sentinel (fault status, or 500 ms without a frame): gp_69ae = 0x7FFF, gp_6805 = gp_6803 = … = 0xFF   # re-asserted every 5 ms

The sentinel lands 510–514 ms after the last frame; until then the last setpoint and request are held. The stock camera sends bits 3:2 ∈ {0, 1} on 6.9 M logged frames and never 2. E

7.2 The feedback-operand filter, 0x28F4C–0x28FC6 (runs every valid tick)

x     = ld.h(gp-0x6a56)  # stock: the wire rate      ★E1 (0x28F4E aa95→0096): x = ld.h(gp-0x6a00) = θ
s_new = ((b·x) >> 10) + ((a·s_old) >> 10)          # b 0xC63EA, a 0xC63E8: stock 1560 / 923 → ★ 8192 / 0
r26   = s_old + s_new                               # 0x28FA4 add r9,r26 (stock and V300)
r26   = clamp(r26, ±C)                              # C 0xC62E6: stock 7680 → ★ 65535
# stock: a 16.5 Hz LPF on the rate, DC gain 30.89.  V300: s_new = 8θ exactly ⇒ r26 = 8θ[n] + 8θ[n−1] = 16θ, no pole

7.3 The guard, 0x29A48–0x29A64

stock:  run the PID iff ramp ≠ 0  OR  request == 1        (0x29A56 bne ; 0x29A5A bne ; 0x29A5C jr 0x2A164)
V300:   ★B2 0x29A50 setfe r8 → cmovne r0,r27,r8   r8 = request ? bVar2 : 0     (r27 = bVar2, dominates every path)

# removes the override-latch wind-up (integrating at ramp 0 with request still 1) and the 0xE4 sentinel pulse (bVar2 is false on 0x7FFF)

7.4 The setpoint stage, 0x28FC8–0x29D6C
