## 4. The top candidate, specified — (ii-d): `S' = y − 4·(n − n_prev)`

### 4.1 What it is, in the cave's own arithmetic (integer mirror, `NotchIntD` in the script)

```python
# V289 cave, 0xC4C00.. (adversary A's listing), unchanged through n:
acc = b0*x + s1 + e ; y = acc >> 14 ; e' = acc & 0x3fff          # 0xC4C00-0xC4C22   x = S (r12), y = notch output (r6)
s2' = b0*x - a2*y ; n = x - y ; s1' = b1*n + s2                   # 0xC4C26-0xC4C46   n in r9
# V290 addition (≈ 7 instructions, pre-clamp):
nh   = n >> 1                      # sar 1        halfword-safe: |n| <= 34345 linear worst case -> |nh| <= 17172
d    = nh - nh_prev                # ld.h gp-0x6c3a ; sub         nh_prev = last tick's nh
st.h nh -> gp-0x6c3a               #              (the halfword the FLAG used; FLAG moves into e's top two bits, 4.3)
r12  = y - (d << 3)                # shl 3 ; sub                  = y - 4*(n - n_prev) to 1 LSB of n
r12  = clamp(r12, +-cal 0xC61BE)   # 0xC4C72-0xC4C82 unchanged   bounds everything downstream exactly as V289 did
```
Transfer of the sum node (S → what the lag receives): **H = N − 4·(1 − z⁻¹)·(1 − N)**. DC: N = 1 ⇒ H = 1 exactly (the
added term has zero DC gain by construction, no error feedback needed for the difference). At 20.036 Hz N = 0 ⇒
H = −4·(1 − z⁻¹) = 0.50 ∠+84°. Above 30 Hz |(1−z⁻¹)(1−N)| ≤ 0.05 and falls to 0 at Nyquist — no HF cost.

## 7. Class (iii) — what excitation remains, and the two colleague hypotheses

- **What V288 proved.** The D-kick from setpoint steps was cut ×0.03 and the bell was unchanged: the ring's size is set by
