Section 13 Timer Array Unit A (TAUA)
This section contains a generic description of the timer array unit A (TAUA).
Caution
TAUA may have unavailable channels depending on a channel combination or 
port I/O selection.
13.1
TAUA Features
Instances
This product has the following number of instances of TAUA.
Instances index n
Throughout this section, each of the TAUA instances is identified by "n" (n = 0 
or 1), such as TAUAn channel output mode register (TAUAnTOM).
Channels index m
TAUA has 16 channels. Throughout this section, each channel is dentified by 
"m" (m = 0 to 15). Thus, a certain channel is denoted as CHm.
The even numbered channels (m = 0, 2, 4, 6, 8, 10, 12, 14) are denoted as
CHm_even.
The odd numbered channels (m = 1, 3, 5, 7, 9, 11, 13, 15) are denoted as 
CHm_odd.
Register addresses
All TAUAn register addresses are given as address offsets to the individual
base addresses <TAUAn_base0>, <TAUAn_base1>.
