This register specifies clocks CK0, CK1, CK2, and CK3_PRE for all channels 
of the PCLK prescaler. CK3 is generated by dividing CK3_PRE by the factor 
specified in TAUAnBRS.
Access
Readable/writable in 16-bit units.
Address
<TAUAn_base0> + 240H
Initial value
FFFFH
This register is initialized by any reset source.

TAUAnBRS - TAUAn Prescaler Baud Rate Setting Register
This register specifies the division factor of prescaler clock CK3.
CK3 is generated by dividing CK3_PRE by the factor specified in this register
plus one. The PCLK prescaler for CK3_PRE is specified in
TAUAnTPS.TAUAnPRS3[3:0].
Access
Readable/writable in 8-bit units.
Address
<TAUAn_base0> + 244H
Initial value
00H
This register is initialized by any reset source.
