Functional Overview
Functional
overview
The timer option module (TAPA) is for use with the timer array unit A (TAUA) 
and TSG2 modules. It provides optional functions for the timers.
• Asynchronous Hi-Z control to deal with pin input 
• Output of the INTn signal from the TAUA as a peak or valley interrupt is 
selectable.
• The INTn signal output by the TAUA provides the basis for the output of two 
conversion-trigger signals for the A/D converter.

19.2.2
Peak and Valley of Timer Counter, and Peak and Valley 
Interrupts
In this document, the period from a TAUA down status (counting-down status) 
to generation of an interrupt by the master channel is defined as the valley 
period, and an interrupt generated to indicate this period is defined as a valley 
interrupt (INT-VLY). The period from a TAUA up status (counting-up status) to 
generation of an interrupt from the master channel is defined as the peak 
period, and an interrupt generated to indicate this period is defined as a peak 
interrupt (INT-PEK).

Abnormal operation in timer motor-control under CPU control leads to rotation

Operating Procedure for Setting a Trigger to Start Conversion by the A/D 
Converter
The operating procedure for setting a trigger to start conversion by the A/D 
converter is as follows.
Operation
States of TAUA and TAPA
Initial settings
Initialize TAUA.
Determine the timer's operating mode.
TAUA and TAPA are stopped.
Setting in the TAPAnCTL1 register.
Set TAPAnATS[1:0] bits (for TAPAnTADOUT0).
Set TAPAnATS[3:2] (for TAPAnTADOUT1).
Start 
operation
Start the TAUA module.
TAUA starts counting.
During operation
TAUA runs in accord with the settings for the 
various functions.
The A/D converter conversion trigger selector 
outputs TAPAnTADOUT0 in accord with the 
settings of TAPAnATS[1:0] or TAPAnTADOUT1 
in accord with the settings of TAPAnATS[3:2], 
based on the slave match detection signal
(TAPAnTCDENS1 or TAPAnTCDENS0) and up/
down input (TAPAnTUDCM0) from the TAUA 
and the valley interrupt signal (TAPAnTIVLY0) 
generated by TAPA.
Stopping 
operation
Stopping the TAUA module.
TAUA stops counting.
