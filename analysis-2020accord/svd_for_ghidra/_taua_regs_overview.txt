Section 13　Timer Array Unit A (TAUA)
13.13.15
Clock Divide Function
(1)
Overview
Summary
This function is used as a frequency divider. The frequency of the input signal 
TAUAnTTINm is divided by a factor related to TAUAnCDRm, and the resulting 
signal is output to TAUAnTTOUTm.
Prerequisites
• TAUAnTTINm should have a fixed frequency.
• The operating mode should be set to interval timer mode. (See table 13-79, 
TAUAnCMORm Settings for Clock Divide Function.)
• The channel output mode should be set to independent channel output 
mode 1. (See section 13.8, Channel Output Modes.)
Functional
description
The counter is started by setting the channel trigger bit 
(TAUAnTS.TAUAnTSm) to 1. This in turn sets TAUAnTE.TAUAnTEm = 1, 
enabling count operation. The current value of TAUAnCDRm is loaded into 
TAUAnCNTm and the counter starts to count down from this value, using 
TAUAnTTINm as a count clock.
When the counter value reaches 0000H, INTTAUAnIm occurs and 
TAUAnTTOUTm signal is toggled. Then, TAUAnCDRm value is loaded into 
TAUAnCNTm to continue operation subsequently. 
The value of TAUAnCDRm can be rewritten at any time. The changed value of 
TAUAnCDRm is applied when the counter starts to count down next time.
The counter can be stopped by setting TAUAnTT.TAUAnTTm = 1. This sets 
TAUAnTE.TAUAnTEm = 0. TAUAnCNTm and TAUAnTTOUTm stop but retain 
their values. The function can be restarted by setting TAUAnTS.TAUAnTSm = 
1. The counter can also be forcibly restarted without making a stop by setting 
TAUAnTS.TAUAnTSm = 1 during operation (forced restart).
Conditions
If the TAUAnCMORm.TAUAnMD0 bit is set to 0, the first interrupt after a start 
or restart is not generated, and therefore TAUAnTTOUTm does not toggle. 
This results in an inverted TAUAnTTOUTm signal compared to when 
TAUAnCMORm.TAUAnMD0 is set to 1. For details, see section 13.10, 
TAUAnTTOUTm Output and INTTAUAnIm Generation when Counter Starts or 
Restarts.
Note
TAUAnTTINm input signals are sampled at the frequency of a sampling clock 
set by TAUAnCMORm.TAUAnCKS[1:0] bits. Therefore, the TAUAnTTOUTm 
output clock cycle has an error of ± 1 sampling clock cycle.
(2)
Equations
• When rising edge detection is selected:
TAUAnTTOUTm frequency = TAUAnTTINm frequency/
[(TAUAnCDRm + 1)  2] 
• When falling edge detection is selected:
TAUAnTTOUTm frequency = TAUAnTTINm frequency/
[(TAUAnCDRm + 1)  2] 
• When falling and rising edge detection is selected:
TAUAnTTOUTm frequency = TAUAnTTINm frequency/
(TAUAnCDRm + 1)
